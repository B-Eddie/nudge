# Changelog

All notable changes to Nudge will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-23

First stable release.

### Added
- Desktop companion character that visualizes work energy and nudges you to rest
- App-aware animations and context-aware phrases per app category
- Configurable break reminders, distraction nudges for games/social/video
- Activity summary: per-category time, breaks taken/interrupted, longest stretch, 31-day history
- Reminder notes the character speaks at the next reminder
- Auto-break on system idle and on sleep
- Launch at login, global hide/show shortcut, multi-monitor + screen-corner positioning
- First-run onboarding flow
- In-app auto-updates via GitHub Releases

### Changed
- Product name capitalized as "Nudge" across the app
