# Security

Nudge runs entirely on your Mac. It has no account system and sends no activity data to a server (see the [privacy page](https://nudge-nine-flame.vercel.app/privacy.html)).

To report a vulnerability, use GitHub's private reporting: **Security > Report a vulnerability** on this repository. Please do not open a public issue for security problems. You can expect a first reply within a week.

The macOS build is not signed or notarized yet. Download it only from this repository's Releases page and compare it with `SHA256SUMS.txt`.
