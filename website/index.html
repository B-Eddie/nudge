Ask on GitHub (opens in a new tab)
Is nudge really free?

Yes. Nudge is free and open source. No account, subscription, or sign-in is required to use the app.

What does it track?

Nudge groups your active apps into categories and records time spent working or resting. Settings and activity are stored locally. Read what stays on your Mac.

Will it get in the way?

You can move and resize your companion, snooze a reminder, or hide it with a shortcut. Perching follows a window without bringing that window to the front.

Which Macs can run it?

The universal macOS download includes Apple silicon and Intel binaries. The current build is not notarized. Installation steps are included below.

First time opening nudge? A quick note for macOS.

This community build is not notarized. After dragging nudge into Applications, open it. If macOS blocks it, review the download in System Settings → Privacy & Security and choose Open Anyway.

Only open a download you trust. You can inspect the source and checksums on the release page (opens in a new tab).
